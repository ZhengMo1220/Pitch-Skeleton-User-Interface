- [ ] **評估第二支側面相機的整合** — 目前程式碼（`cv_thread.py`）只有 `SN1`/`SN2` 兩組序號（正面+側面各一），論文原始架構為 2 側面 + 1 正面，若要完整對應需新增程式碼支援第三台相機
- [ ] **評估「5 支攝影機監看程式」與本系統的介接方式** — 確認是否需要共用相機驅動層或 GPU 資源

- [ ] **釐清「3D」分頁（`video_widget_2.py`）與 `stereo_calib.json` 的參數不一致問題** — `video_widget_2.py` 內建構子中 `K_F`（正面內參）、`K_S`（側面內參）、`F`（Fundamental Matrix）全部是寫死在程式碼裡的數字，且 `F` 有 5 組歷史版本被註解保留（僅最後一組 `#0505` 生效），與 `stereo_calib.json` 裡的數值完全不同（例：`K_F` 的 fx 為 7927.87，`stereo_calib.json` 為 1060.45，差約 7.5 倍）。代表系統中至少存在兩套互不一致的相機校正參數，3D 重建實際使用的是寫死在程式碼裡這一套，不是 `stereo_calib.json`；後續無論如何都要處理，可與上一項的全新校正流程一併規劃（校正完成後應改為從單一檔案讀取，不要再寫死在程式碼裡）

## 背景知識參考

系統設計依據學長姐碩士論文：《基於2D-to-3D Diffusion-Transformer網路之棒球投球骨架動作切分及動作分析》（施邑穎，國立成功大學人工智慧科技碩士學位學程）

- 原始硬體架設：3 部高速工業相機（2 側面 + 1 正面），179fps，BayerRG8，GPIO 硬體同步觸發
- 鏡頭規格：側面 KOWA LM8HC 8mm F/1.8（視角廣，涵蓋完整投球動作）；正面 KOWA LM50HC 50mm F/1.4（解析度高，關節辨識精度佳）
- 核心流程：相機校正 → YOLOv11+ViTPose 2D 骨架偵測 → 三角測量重建 3D 骨架 → 投球四階段切分（FC/MER/BR）→ 生物力學參數計算
- 系統架構採「即時擷取」與「離線分析」分離設計，避免即時運算拖慢影像擷取效能
- 詳細細節（GUI 分頁對應、相機序號、畫面左右對應）見 [DEVELOPMENT.md](DEVELOPMENT.md)
