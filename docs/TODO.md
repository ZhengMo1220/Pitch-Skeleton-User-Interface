## 背景知識參考

系統設計依據學長姐碩士論文：《基於2D-to-3D Diffusion-Transformer網路之棒球投球骨架動作切分及動作分析》（施邑穎，國立成功大學人工智慧科技碩士學位學程）

- 原始硬體架設：3 部高速工業相機（2 側面 + 1 正面），179fps，BayerRG8，GPIO 硬體同步觸發
- 鏡頭規格：側面 KOWA LM8HC 8mm F/1.8（視角廣，涵蓋完整投球動作）；正面 KOWA LM50HC 50mm F/1.4（解析度高，關節辨識精度佳）
- 核心流程：相機校正 → YOLOv11+ViTPose 2D 骨架偵測 → 三角測量重建 3D 骨架 → 投球四階段切分（FC/MER/BR）→ 生物力學參數計算
- 系統架構採「即時擷取」與「離線分析」分離設計，避免即時運算拖慢影像擷取效能
- 詳細細節（GUI 分頁對應、相機序號、畫面左右對應）見 [DEVELOPMENT.md](DEVELOPMENT.md)
